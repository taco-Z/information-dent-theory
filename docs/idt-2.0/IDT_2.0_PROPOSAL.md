## 1. 概要と継承する中核

情報が通過するだけでなく持続的な構造的痕跡（くぼみ）を残し、その痕跡がノード間の相互作用を変えることで、複雑性が形成・維持されるという枠組みを継承する。

既存の日本語READMEとPDFは蓄積とネットワークを中心にし、英語READMEとCore Equationsは重力・ブラックホール・宇宙進化への接続も提案している。2.0では両方を残し、ネットワーク上の定義、物理への接続仮説、観測事実を区別する。

情報 → 持続的痕跡 → 相互依存と統合 → 複雑な構造、という流れを研究の出発点とする。そこから重力などへ進む矢印は、別途検証が必要な仮説である。

## 3. イデア構造の基本仮説

複雑なくぼみ体が対象を認識すると、その対象に関する表象・記録・分類・記憶などを介して情報リンクが形成または更新され、関係ネットワークが変わる、と仮定する。

一本の木について、分類する、写真を撮る、記憶を関連付ける、といった過程は、認識主体や記録媒体を含むネットワークの変化として表す。木そのものの質量や物理的情報密度が認識だけで増すことは、この記述から導かれない。

「強く認識する」は発想段階の言葉であり、実験では保持時間、再同定の成績、文脈間の転移、リンクの持続など、測定できる基準へ置き換える必要がある。リンクは必ず増えるとは限らず、誤認、忘却、統合、削除、重複による変化も許す。

人間以外の生物やAIをモデルの候補に含めることはできる。ただし、認識課題を実行する能力と主観的意識の存在は別の問いであり、AIを含むことはその意識の証明を意味しない。「くぼみ体＝意識」とは定義しない。

## 4. 数理モデルの継承と適用条件

既存の記号を維持する。以下は情報ネットワークのモデル上の定義であり、物理法則ではない。

$$
d_i(t)=\int_0^t \phi(x_i(\tau))\,d\tau
$$

$$
\mathcal{P}(t)=\sum_{i\in V}\alpha d_i(t)+\sum_{(i,j)\in E}\beta w_{ij}(t)d_i(t)d_j(t)
$$

$$
\mathcal{C}(t)=\sum_{i\in V}d_i(t)^2+\lambda\sum_{(i,j)\in E}w_{ij}(t)d_i(t)d_j(t)
$$

`d_i`: くぼみの深さ、`x_i`: 情報状態、`w_ij`: 結合強度。`P`はネットワーク上のスコアであり、重力ポテンシャルと同じ量と扱わない。`C`も候補指標であり、複雑性一般を測ることが確立した量ではない。

例えば全量を無次元化して使用する場合、時間にも基準時間を設け、積分の入力を基準時間あたりの無次元蓄積率とする。物理単位を与える場合には、`alpha`、`beta`、`lambda`を含む全項の次元を別途そろえる。ここでは値や物理単位を新たに確定しない。

`E`の有向・無向の別、自己リンクの可否、無向辺を一回だけ数える規則、ノード集合を固定する期間を指定しないと、比較値は一意にならない。ノード数の多さと統合度も区別する。

固定された有限グラフで微分可能とすると、既存の定義から次式を得る。

$$
\dot{\mathcal{C}}=2\sum_i d_i\dot d_i+\lambda\sum_{(i,j)\in E}\left[\dot w_{ij}d_id_j+w_{ij}(\dot d_i d_j+d_i\dot d_j)\right]
$$

したがって、`d_i >= 0`、`dot d_i >= 0`、`w_ij >= 0`、`dot w_ij >= 0`、`lambda >= 0`なら非減少となる。厳密な増加には寄与する項の少なくとも一つが正であることが必要。認識や持続的な蓄積だけから常に `dot C > 0` とは言えない。辺・ノードの追加削除時は連続微分とは別に差分を評価する。

イデア構造の試案は、主体・対象・表象・記録などをノードとするグラフ `G_sem(t)=(V_sem,E_sem(t))` として記述できる。既存の `w_ij` を意味関係の重みへ用いる場合は、新たな用途と測定規則を宣言する。接続数や重みの総和は候補指標にすぎず、情報量・意味の豊かさ・物理密度の普遍的な定義ではない。恣意的な重複ノードで値が増える指標は比較前に改善する。

## 5. 意味情報と重力の間の未検証の接続

認識によって意味情報や関係構造が増加する可能性と、それが物理的情報密度・時空曲率・重力へ追加で寄与する可能性は、別々に検証する。

現段階では、`意味リンク増加 → 物理的情報密度増加 → 重力増加`を導く法則、換算係数、測定結果は提示していない。記憶や計算を支える媒体のエネルギー変化と、意味そのものに固有の重力寄与を混同しない。

物理モデルへ進めるには、少なくとも以下が必要である。

1. 情報密度の操作的定義、単位、粗視化尺度、座標変更に対する扱い。
2. エネルギー・運動量、保存則、因果律との整合、および既存の重力理論へ戻る極限。
3. ネットワーク量から物理場への明示的な対応と、通常の物質・エネルギー寄与を二重計上しない規則。
4. 既存理論と異なる定量的予測、誤差込みの検証方法、支持されない条件。

Core Equationsの `Phi = alpha I` は接続仮説として保留する。`Phi`を単位質量あたりの重力ポテンシャルとするなら、加速度は `a = -grad Phi`、力は `F = m a` と区別する。ポテンシャルエネルギーを採用する場合は別の定義となる。

既存の銀河式の `M/r^2` と `I_core I_global/r` は、そのままでは次元や係数が未確定である。ブラックホール条件の有限の `I_max` から勾配発散は自動的に導けず、発散と事象の地平面も同一ではない。これらを観測との一致や導出済みの結果として扱わない。

## 6. ダークマターの分布差をどう検討するか

ダークマターが少ないと推定される銀河と、多いと推定される銀河の差は、可視物質と別の成分を想定する実体仮説を検討する材料になる。「実体」の粒子種やIDT上の機構を、それだけで確定するものではない。

ここでの分布差には、銀河ごとの推定含有率、銀河内の半径方向の分布、周囲環境や空間配置の差がある。互いに別の観測量として扱い、「少ない銀河がある」というだけで空間的な分離が確認されたとはしない。

NGC 1052-DF2/DF4などの報告は参考例であり、IDTの予測成功例ではない。衝突でガスとダークマターが分離する形成シナリオが提案されている[S1]。一方、DF2の距離と推定含有量については、異なる距離推定法による再検討も報告されている[S2]。

比較では距離、速度分散と標本数、恒星質量光度比、軌道異方性、力学的平衡、潮汐作用、ガス、観測半径、選択効果を確認する。修正重力についても、個別の理論の予測と外場効果などを評価する[S3]。銀河分布差だけで修正重力全体を排除したとは言えず、両者の識別は本案では未決着とする。

IDTとしては、情報構造の指標を質量不一致から独立に測定する方法、少ない側と多い側の双方への予測、回転曲線以外のレンズ効果などとの整合が必要。観測に合わせて指標を後付け定義する段階では、競合理論から識別する力がない。

## 7. イデア宇宙論との関係

イデア宇宙論は、認識・関係形成・情報ネットワークを宇宙全体の記述と結び付けて考えるための仮称とする。情報くぼみ理論を飲み込む上位理論、あるいはその下位理論とは固定しない。

ノードと痕跡のミクロな記述、くぼみ体と認識の中間的な記述、銀河・宇宙のマクロな記述を、適用領域の異なる視点として比較する。どの尺度が重要・優位かを決めず、共通変数、粗視化、対応関係、適用できない条件が明確になってから統合の可否を検討する。

## 8. 量子測定との境界

量子測定で系・装置・環境の相互作用を扱うことと、意味や主観的意識による認識を扱うことは区別する。量子測定に意識が必要であるとは実証されていない。デコヒーレンスは環境との相互作用による干渉の抑制を説明するが、それだけで測定問題の全解決や特定の解釈の確定を意味しない[S4]。

量子測定を「認識が物理的情報密度を増す」ことの実証例には用いない。IDTのイデア構造は、量子論を根拠として成立済みとすることなく、独立した概念仮説として検討する。

## 9. 検証課題と限界

| 課題 | 必要な比較 | 支持が弱まる条件・限界 |
| --- | --- | --- |
| 認識による持続的リンク形成 | 認識課題と単なる保存・ランダム関連付けを、媒体と課題条件をそろえて比較 | 事前に決めた保持・関係利用の指標に差がない。差があっても既存の学習モデルで説明できればIDT固有の支持ではない |
| 複雑性の形成 | 固定ノードで蓄積・結合・忘却を分けて評価 | 結果が符号や尺度の選び方だけで決まる。Cの増大だけでは統合機能の向上を示さない |
| 銀河の質量不一致 | 独立に定義した構造指標から事前予測し、少ない側・多い側のデータで検証 | 同じ係数・条件で両方を説明できない、または自由度を考慮すると競合理論を上回らない |
| 意味固有の重力寄与 | 媒体のエネルギー・熱・質量などを統制した定量予測 | 現在は結合法則も効果量もなく、実験計画・反証可能な物理予測には未到達 |

本改訂で実施したのは文献照合と文書・数式の整合性確認であり、銀河データ解析、認識実験、重力測定ではない。宇宙の複雑性が常に増すという旧来の宇宙進化像も、普遍法則として検証済みとは扱わない。
